# Changelog

All notable dataset changes are documented here.

## [1.0.0] - 2026-07-26

### Added

- 5,000 synthetic Turkish daily-life conversations across 35 balanced topics.
- Scenario-family grouped train, validation, and test splits.
- Nested JSONL and Parquet release artifacts.
- Explicit per-record AI-assisted synthetic provenance.
- Deterministic offline generator, validator, tests, CI workflow, manifest, and SHA-256 checksums.
- Complete sample matrices for topic × split and topic × turn-count review.
